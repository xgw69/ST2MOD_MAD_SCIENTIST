## 1. 核心机制

### 1.1 修复 Repair / 机器耐久 Machine Durability

- 机器耐久初始 **0**，上限 **20**。
- **修复 N** = 机器耐久 +N。
- 部分牌 **消耗 N 点机器耐久**；只要机器没爆炸，耐久不够也能打（透支）。
- 耐久变为**负数**时机器爆炸（刚好 0 不爆炸）：
  - 受到 **2 × 透支量** 的伤害（例：耐久 3，消耗 5 → 透支 2 → 受 4 点伤害）
  - 本场战斗内，所有消耗耐久的牌无法再打出，修复失效
- **【我定】** 爆炸后耐久视为 0，并锁定到战斗结束。

### 1.2 融合 Fusion

- 把手牌中的若干张牌合并成**一张**融合牌，打出时**按选择顺序**依次结算所有原牌效果。
- 费用 = 所有融合牌费用之和。
- 含 X 费牌时，融合牌费用为 X；轮到 X 费原牌结算时，按融合牌的 X 取值计算。
- 词条继承：融合前任意一张牌有某词条（除"不可打出"），融合牌都有（消耗、保留、固有、重放等）。
- 诅咒 / 状态牌不能融合。
- 融合两张"不可打出"牌不影响融合牌可打出。
- 融合牌被消耗 = 整张消耗一次。
- 重放作用于整张融合牌。
- **【我定】** 融合牌的名字显示为"融合体"（或第一张牌名 + "…"），描述拼接所有原牌。

### 1.3 疯狂科学 Mad Science

- 原版 `MAD_SCIENCE` 是一张**可变形态**牌：类型（攻击/技能/能力）+ 词条（Violence / Sapping / Choking / Energized / Wisdom / Chaos / Expertise / Curious / Improvement）。
- 本设计里"疯狂科学"指这些形态；"9 张"具体组合**待确认**（见第 6 节 Q4）。

### 1.4 愧疚 Guilt

- 由「伦理边界」生成；战斗中加入抽牌堆，战斗结束后加入牌组。
- 具体效果**待确认**（见 Q17）；暂定为不可打出的诅咒（无法移除）。

## 5. 实现难度评估

### 🔴 高（需要先定架构，否则返工）

1. **融合系统**：融合牌模型（多张牌合成一张、按序结算、费用求和、X 费、词条继承、重放整张、消耗整张、描述拼接）、多选 UI、敌人死亡后的空打。**这是整个 mod 的核心，工作量最大。**
2. **机器耐久**：需要可见计数器（HUD）+ 上限 20 + 负数爆炸 + 爆炸后锁定；是否跨战斗持久决定要不要存档。
3. **大融合 / 组装 / 处理**：批量选择手牌/抽牌堆的卡并入，且要处理融合嵌套（融合牌再融合）。
   - 融合牌类型优先级：**能力 > 技能 > 攻击**（只要材料中有能力牌，融合牌就是能力牌，打出后不会回到手牌）。
4. **丧失理智**：战斗内"永久移除牌组一张牌"，需要战斗外的牌组修改。
5. **执迷不误**：手牌存在时必须优先打出 + 禁止其他技能（CanPlay/UI 双向拦截）。
6. **灵魂研究**：致死替代 + 最大生命变化 + 消耗所有能力牌。
7. **全自动运行**：消耗堆里每回合自动打出，需要扫描与自动出牌逻辑。

### 🟡 中

- X 费多段伤害（X射线）、随机敌人（灼热地面）、下回合开始效果（备用尖刺/备用药剂/思考/计划）
- 斩杀触发（巨型扳手）、敌人血量取余（全能修正）
- 按卡名含"爆破"触发（爆破装置）
- 疯狂科学的 9 种形态（取决于 Q4 的定义）

### 🟢 低（标准效果）

伤害、格挡、抽牌、能量、力量/敏捷/荆棘、易伤/虚弱/中毒、缓冲、无实体、人工制品、固有、保留、消耗。

### 6.2 融合规则（我们的版本，与火堆融合不同）

- 费用 = **所有母卡费用之和**（不是火堆融合的"最大+1"）
- 含 X 费母卡时：融合牌为 X 费，打出时消耗所有能量；只有 X 费母卡按 X 结算，其余母卡只结算一次
- 词条并集；消耗整张；重放整张
- 融合卡名称/卡图/代码结构参考 `CardFusion.FusedCard`（本机 workshop `3747615796`），但**不依赖**该 mod
